# Profile artwork

Original, code-based artwork for Francesco Fischetti’s GitHub profile.

`artwork.html` and `artwork.css` define the compositions. The source uses local Space Grotesk fonts, distributed with their SIL Open Font License in `fonts/`.

Open `artwork.html?scene=hero`, `?scene=feature`, `?scene=pablo`, `?scene=magica` or `?scene=avatar`. Add `&mobile=1` for the phone composition. The sizes are set in the CSS; screenshots should match those sizes with a pixel ratio of 1.5 or higher. Wait for local fonts and images before capturing.

The public-site screenshots in `previews/` were captured on 31 October 2026:

- `https://www.trademove.tech/it`: the public analytics example. All trading records shown are illustrative, as labelled by the product itself.
- `https://pablofrancesconi.com/`: the public homepage.
- `https://pizzeria-magica.vercel.app/`: the public website preview.

No authenticated app screens are used.

The header GIF is a five-second loop made from the native CSS glow and sheen. Its words remain stationary. Mobile readers receive a static phone composition; desktop readers with reduced motion enabled receive a static header through the README’s `picture` sources.

`avatar-ff.png` is an optional personal avatar. It is provided as a file; it does not change the GitHub account picture automatically.
